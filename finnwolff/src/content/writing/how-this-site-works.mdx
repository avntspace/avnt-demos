Every post is a single text file in `src/content/writing/`. Write in Markdown, set a few fields at the top, push, and it's live. There is no editor to log into and no database.

## Writing a post

Run `npm run new "Title of the post"` and a new draft appears with today's date. Drafts are visible while previewing locally but stay off the live site until `draft: false`. Each post declares a **type** (essay, note, or analysis), which is how the archive is filtered, and any number of **tags**, which get their own pages automatically.

Regular Markdown covers most of what you'll need: *emphasis*, **bold**, [links](/writing/), lists, and quotes.

## Footnotes and asides

Footnotes are useful for keeping the main line of an argument clean while still showing your work.[^1] They're collected at the bottom of the post automatically.

Posts saved as `.mdx` can also use components, like the callout at the top of this page:

## Tables and data

Analyses often need a table. Numbers line up in columns automatically.

| Base case   | Current trajectory |   1,000 |   2,400 |
| Upside      | Faster adoption   |   1,000 |   4,100 |
| Downside    | Slower adoption   |   1,000 |   1,300 |

## Code

Code is highlighted and adapts to light and dark mode.

```python
def compound(principal: float, rate: float, years: int) -> float:
    return principal * (1 + rate) ** years
```

## Publishing

When a post is ready, set `draft: false` and push. The home page, archive, topic pages, RSS feed, and sitemap all update on their own. Set `featured: true` on your best pieces to pin them under "Start here" on the home page.
